# Claude Code Project Instructions

## Project Overview
This is the OpenClaw project repository. Please follow these guidelines when assisting with code.

## Development Guidelines

### Code Standards
- Write clean, maintainable, and well-documented code
- Follow existing code patterns and conventions in the project
- Add comments for complex logic
- Keep functions focused and single-purpose

### Testing
- Write tests for new functionality
- Run existing tests before committing changes
- Ensure all tests pass before submitting changes

### Commits
- Write clear, descriptive commit messages
- Make small, focused commits
- Reference issue numbers in commit messages when applicable

### Security
- Never commit secrets, API keys, or credentials
- Always sanitize user inputs
- Follow security best practices for the tech stack

### Before Making Changes
- Understand the existing codebase structure
- Read relevant documentation
- Ask for clarification if requirements are unclear

### Workflow
- Only make explicitly requested changes
- Do not refactor or optimize unless specifically asked
- Test changes locally before committing
- Keep changes minimal and focused
