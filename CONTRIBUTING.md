# Contributing to OpenClaw

Thank you for your interest in contributing to OpenClaw!

## AI Coding Assistant Configuration

This project is configured for use with AI coding assistants including:

- **Claude Code**: Configuration in `.claude/settings.json` and `CLAUDE.md`
- **GitHub Copilot**: Instructions in `.github/copilot-instructions.md`
- **Cursor AI**: Rules in `.cursorrules`

### AI Assistant Guidelines

When using AI coding assistants on this project:

1. **Follow Existing Patterns**: AI assistants are configured to maintain consistency with existing code
2. **Security First**: The configuration blocks access to sensitive files like `.env` and private keys
3. **Test Your Changes**: Always run tests before committing
4. **Minimal Changes**: Make the smallest changes necessary to accomplish the goal
5. **Ask for Confirmation**: Assistants are configured to ask before making significant changes like installing dependencies

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a new branch for your feature or bugfix
4. Make your changes
5. Test your changes thoroughly
6. Commit with clear, descriptive messages
7. Push to your fork
8. Open a Pull Request

## Code Standards

- Write clean, readable code
- Follow the project's coding conventions
- Add tests for new functionality
- Update documentation as needed
- Ensure all tests pass before submitting

## Security

- Never commit secrets, API keys, or credentials
- Follow security best practices
- Report security vulnerabilities responsibly

## Questions?

If you have questions about contributing, please open an issue for discussion.
